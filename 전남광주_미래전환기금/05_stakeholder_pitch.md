## 1. 민형배 당선자용

### 1.1 30초 메시지

> "20조 원을 4년 동안 다 쓰면 4년 후 남는 건 유지관리비와 정치 논란뿐입니다. 12조 원을 미래전환기금으로 묶으면 임기가 끝난 뒤에도 매년 4,000억~5,000억 원이 전남광주를 위해 일합니다. 이것이 진짜 100년 대계입니다."

### 1.2 1페이지 보고

**왜 지금인가** — 교부조건이 확정되고 나면 사후 기금화는 보조금법상 불가능해질 수 있다. **특별법·교부조건 협상이 골든타임**이다.

**두 선택지**

| 구분 | 전통 방식 | 미래전환기금 |
|---|---|---|
| 4년 후 재원 | 0원 | 매년 수익 지속 |
| 연 4% 수익 | 없음 | 4,800억 원(12조 기준) |
| 20년 후 | 유지관리비 잔존 | 누적 9.6조 원 |

**권장안** — 12조 기금 + 8조 직접투자. 8조로 임기 내 가시성과(AI·에너지·농수축산·청년), 12조로 임기 후 지속재원.

**지금 필요한 결정** — 교부조건에 **"기금 출연 가능성 명시"** 한 줄.

### 1.3 설득 포인트

- **임기-미래세대 균형** — 8조 직접투자는 임기 성과, 12조 기금은 100년 레거시
- **정치적 나눠먹기 방지** — 기금화가 오히려 지역 갈등 해소 + 리더십 강화
- **수용성** — 중앙정부·국회가 받기 쉬운 책임재정 모델
- **상징성** — 노르웨이 GPFG처럼, 통합지원금을 영구 성장자본으로 만든 첫 지방정부

## 2. 중앙정부용

### 2.1 핵심 메시지

> "전남광주 미래전환기금은 지방에 돈을 퍼주는 방식이 아니라, 투입한 20조 원이 낭비되지 않고 세대를 넘어 작동하도록 제도화하는 책임재정 혁신 모델입니다."

### 2.2 설득 포인트

| 포인트 | 내용 |
|---|---|
| 예산낭비 방지 | 원금보전·지출상한·외부감사·의회보고 |
| 지방재정 자립 | 4년 후 중앙 의존도 영구 감소 |
| 균형발전 표준 | 향후 초광역 통합(부산·경남 등) 표준모델 |
| 관리 용이 | 교부조건 명시·성과공시·외부감사로 사후 감독 가능 |

### 2.3 우려 → 답변

- "보조금을 투자에?" → 특별법·교부조건 명시 시 해소(전제 조건)
- "손실 책임은?" → 위원회·운용기관·감사인 3단계 책임 + 중앙 감독권
- "형평성?" → 최초 통합 사례, 성공 시 동일 기준 표준화

### 3.1 핵심 메시지

> "20조 원은 역대 최대 단일 지방재정 지원입니다. 그만큼 강한 통제가 필요합니다. 기금형은 원금보전·지출상한·외부감사·의회보고·정보공개로 국회가 가장 통제하기 쉬운 구조입니다."

### 3.2 설득 포인트

| 포인트 | 내용 |
|---|---|
| 보조금 관리 강화 | 교부조건 명시 → 용도 외 사용 원천 차단 |
| 과다지출 방지 | 노르웨이식 3~5% 지출률 + 원금 의회 2/3 동의 |
| 감시 용이 | 분기 공시·연간 의회보고·지역투자 성과지표 |
| 특혜 방지 | 특정기업 직접투자 금지·운용기관 공개경쟁·이해충돌 신고 |

### 3.3 상임위별 포인트

- **기재위** — 지방재정 자립·균형발전 예산 효율

- **산자위** — 지역 미래산업 투자 지속성·수도권 집중 완화

## 5. 금융기관용

### 5.1 핵심 메시지

> "전남광주 미래전환기금은 국내 최초급 지방정부형 대규모 장기 OCIO 모델입니다. 8조~12조 원 규모로 국민연금식 자산배분을 벤치마크하며, 지역전략투자와 글로벌 분산투자를 결합합니다. 공개경쟁으로 OCIO 경험 기관을 선정할 예정입니다."

### 5.2 기금 개요

| 항목 | 내용 |
|---|---|
| 규모 | 8·12·15조 시나리오 |
| 기간 | 영구(원금보전) |
| 방식 | OCIO 위탁 |
| 자산배분 | 글로벌 분산(해외주식 35%·대체 15% 등) |
| 지역전략투자 | 5%(AI·에너지·농수축산·바이오) |
| 선정 | RFI→RFP→공개경쟁→위원회 |

### 5.3 참여 가치

- **규모** — 국내 지방기금 최대급 단일 수임
- **기간** — 영구기금, 장기 파트너십
- **복합성** — 글로벌 분산+대체투자+지역전략투자 종합 역량
- **레퍼런스** — 국내 최초 지방정부형 대규모 OCIO

### 5.4 접촉 문장

> "전남광주특별시 출범에 따른 중앙정부 지원 재원을 단기 지출하지 않고 장기 미래전환기금으로 조성하는 방안을 검토 중입니다. 국민연금기금의 장기자산배분 원칙을 벤치마크하되, 실제 운용은 공적기금 OCIO 경험 기관을 대상으로 공개경쟁으로 검토할 예정입니다. 귀사의 공적기금 OCIO 경험을 바탕으로 지방정부형 장기기금 설계 가능성에 대해 사전 의견을 듣고자 합니다."
