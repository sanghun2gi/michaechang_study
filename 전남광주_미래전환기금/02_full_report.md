## 1. 개요 및 정책 배경

### 1.1 전남광주특별시 출범

전남광주특별시는 광주광역시와 전라남도의 행정통합으로 출범하는 대한민국 최초 초광역 통합특별시이다. 2026년 7월 출범, 인구 약 320만 명의 메가시티를 목표로 한다. 통합의 핵심 재정 동력은 중앙정부의 4년간 최대 20조 원 규모 지원이다.

### 1.2 20조 원의 성격 — '예산'이 아니라 '자본금'

이 재원은 일반 국고보조사업과 근본적으로 다르다.

| 관점 | 일반 보조금 | 전남광주 20조 원 |
|---|---|---|
| 규모 | 사업 단위 | 단일 지방정부 역대 최대 |
| 성격 | 특정 사업비 | 통합특별시 초기 자본금 |
| 반복성 | 연례 반복 가능 | 4년 한정·일회성 |
| 의미 | 운영 보전 | 구조 결정 |

### 1.3 핵심 질문

> 20조 원을 4년 안에 쓰고 끝낼 것인가, 아니면 30·50·100년 동안 작동하는 지속 가능한 성장자본으로 만들 것인가?

## 2. 문제 진단 — 소멸성 예산의 함정

### 2.1 반복되는 4대 지출 패턴

| 패턴 | 단기 효과 | 구조적 문제 |
|---|---|---|
| SOC 중심(도로·청사·체육관) | 가시성 높음 | 완공 후 유지관리비 영구 부담 |
| 산업단지 조성 | 유치 명분 | 미분양·중복투자 |
| 보조금 살포 | 체감 즉시 | 의존성 심화 |
| 숙원사업 분산 | 반발 완화 | 전략성 소멸 |

### 2.2 구조적 귀결

```
[예산 모델]  20조 → 4년 집행 → 0원 + 유지관리비 + 정치갈등
[자본 모델]  20조 → 기금 조성 → 연 수익 → 지속 투자 → 미래세대 승계
```

> 단기 집행 일변도는 **4년 후 재원 소멸**이 확정적이라는 점에서, 변동성을 이유로 한 기금 반대론보다 오히려 위험이 크다.

## 3. 기금형 운용의 이론적 근거

### 3.1 영구기금(Permanent Fund) 3원칙

| 원칙 | 내용 |
|---|---|
| 원금 불가침 | 원금은 미래세대 자산, 현세대는 수익만 사용 |
| 지출 상한 | 연간 지출 ≤ 장기 기대실질수익률 |
| 세대 형평 | 일시적 재원을 세대 간 공유하는 메커니즘 |

### 3.2 전남광주 적용 정당성

- **일시성** — 4년 한정 지원, 반복 기대 불가 → 영구기금 적합
- **공공성** — 320만 시민 전체의 공공재
- **세대 책임** — 현세대 소비 시 미래세대 박탈
- **규모 효율** — 대규모 단일 기금이 분산 소액예산보다 운용 효율 우위

### 3.3 Double Bottom Line

아일랜드 ISIF 모델처럼 **재무적 수익**과 **지역경제 파급효과**를 동시 추구한다. 순수 재정보조와 달리 지역전략투자도 **금융투자 형태**로 집행하여 회수 가능성을 확보한다.

## 5. 국내 사례

### 5.1 국민연금기금 — 벤치마크 대상

| 벤치마크 포인트 | 전남광주 적용 |
|---|---|
| 글로벌 분산(해외 50%+) | 해외주식 35%+해외채권 10% |
| 중기자산배분(5년 목표비중) | 투자정책서 5년 주기 |
| 위험관리(VaR·손실한도) | 위원회 한도 설정 |
| 직접+위탁 병행 | OCIO 위탁 중심 |
| 연간 성과 공시 | 분기 공시 의무화 |

> **반드시 명심** — 포트폴리오 *복제*가 아니라 *원칙 벤치마크*. 전남광주 기금의 규모·목적·법적 구조·지역 특수성에 맞춰 **독자 설계**한다.

### 5.2 주택도시기금 OCIO — 국내 실증 모델

- 수십조 원 규모 공적기금 여유자금을 전담운용기관에 위탁
- 미래에셋자산운용이 전담운용기관으로 선정된 경험 보유 → **OCIO 구조의 국내 실증 사례**
- 공개경쟁 선정 절차·수수료 체계·성과평가 방식 직접 참조 가능

### 5.3 한국투자공사(KIC)

- 외환보유액·공적기금의 글로벌 분산투자 전문
- 해외 대체투자·글로벌 주식 운용 방법론, KIC 출신 전문가 자문그룹 활용 검토

## 6. 국민연금 직접위탁의 한계와 OCIO 대안

### 6.1 직접위탁의 5대 한계

| 쟁점 | 내용 |
|---|---|
| 법적 목적 | 국민연금기금은 가입자·수급자 전용 — 지방자금 수탁 근거 부재 |
| 자금 혼합 | 지방자금-연금기금 혼합운용 제도적 부적절 |
| 별도 계정 | 별도 수탁 운용 명시 근거 마련 필요 |
| 책임 구조 | 손실 시 공단·지방·중앙 책임소재 불명확 |
| 정치 논란 | 노후자금을 지역기금에 활용한다는 비판 가능 |

### 6.2 현실적 대안 6단계

1. 국민연금식 자산배분 **원칙 벤치마크** (직접위탁 아님)
2. 국민연금·기금운용본부 **출신 전문가 자문그룹** 구성
3. 공적기금 OCIO 경험 기관 대상 **RFI**
4. **공개경쟁** OCIO 선정
5. **복수 기관 분산 위탁**
6. 기금운용위원회가 투자정책서·위험한도 **통제**

| 구분 | 8조 기금화 | **12조 기금화(권장)** | 15조 기금화 |

## 9. OCIO 위탁운용 구조

### 9.1 도입 이유

| 이유 | 내용 |
|---|---|
| 전문성 | 지방정부 직접 운용 인력 확보 불가 |
| 이해충돌 방지 | 외부 운용 → 정치 개입 차단 |
| 글로벌 네트워크 | 해외자산 운용 파트너십 |
| 성과 책임 | 계약 기반 명확한 책임 |
| 독립성 | 정치 압력으로부터 운용 보호 |

### 9.2 선정 절차

```
RFI(시장검증) → RFP(제안요청) → 외부전문가 평가위원회 → 위원회 의결 → 복수기관 분산위탁
```

### 9.3 RFI 후보군

미래에셋자산운용(주택도시기금 OCIO 경험)·삼성·KB·한국투자신탁·NH·한화 등 — **모두 동등한 공개경쟁 후보군**이며 사전 내정은 없다.

## 10. 법률·제도 체계

### 10.1 최대 리스크

> 20조 원이 보조금·교부금 성격일 때 곧바로 금융투자기금에 적립하면 「보조금 관리에 관한 법률」상 **용도 외 사용** 문제 발생. → **교부조건에 "기금 출연 가능성" 사전 명시**가 선결 과제.

### 10.2 법령 검토 우선순위

| 법령 | 검토 핵심 |
|---|---|
| 보조금 관리에 관한 법률 | 기금 출연 = 목적 외 사용 여부 |
| 지방자치단체 기금관리기본법 | 기금 설치 요건 |
| 지방재정법 | 기금 운용 적정성 |
| 전남광주통합특별법 | 특례 부여·출연 근거 |
| 자본시장법·외국환거래법 | OCIO·해외투자 적용 규정 |

### 10.3 5단 근거 체계

특별법(설치·출연 근거) → 시행령(운용·위탁 기준) → 조례(목적·위원회·공시) → 교부조건(출연 명시) → 투자정책서(자산배분·한도)

## 17. 결론 및 8대 정책 제언

전남광주의 20조 원은 단순 행정통합 인센티브가 아니라, 수도권 집중·인구감소·청년유출·재정 의존성을 극복할 **역사적 기회**다. 단기 분산 집행 시 4년 후 유지관리비와 정치갈등만 남지만, 12조 원을 기금화하면 중앙지원 종료 후에도 **매년 수천억 원**의 독자 재원이 작동한다.

### 8대 제언

1. 원금은 원칙적으로 보전한다
2. 운용수익 중심으로 지출한다
3. 국민연금식 자산배분 원칙을 **벤치마크**한다 (복제 아님)
4. 전문기관은 RFI·공개경쟁으로 검토한다 (특혜 차단)
5. 특별법·시행령·조례·교부조건에 **법적 근거를 명시**한다 (최우선)
6. 지역전략투자는 전체의 일부로 제한한다
7. AI·에너지·농수축산·바이오·모빌리티·청년·대학에 집중한다
8. 모든 성과·지출을 공개한다

> **최종 명제** — 전남광주는 20조 원을 *소비*하는 도시가 아니라, *자본화*하여 대한민국 균형발전의 새 표준을 만드는 도시가 되어야 한다.
