## 1. 국민연금 벤치마크 원칙

### 1.1 국민연금 자산배분의 핵심 시사점

국민연금기금의 운용 방식에서 전남광주 미래전환기금이 벤치마크할 원칙은 다음과 같다:

| 원칙 | 국민연금 방식 | 전남광주 적용 방향 |
|---|---|---|
| 장기 투자 | 10년 이상 장기 시계 | 영구기금 운용 원칙 |
| 글로벌 분산 | 해외투자 50% 이상 | 해외주식 35%+해외채권 10% |
| 자산군 다각화 | 주식·채권·대체투자 | 동일 원칙 적용 |
| 중기자산배분 | 5년 단위 목표비중 | 투자정책서 5년 주기 |
| 위험관리 | VaR, 손실한도 | 기금운용위원회 한도 설정 |
| 직접+위탁 | 직접운용+외부위탁 | OCIO 위탁 중심 |
| 성과공시 | 연간 보고서 공개 | 분기 공시 의무화 |

> **핵심 주의사항**: 위 내용은 국민연금 포트폴리오를 **복제**하는 것이 아니라, 장기·분산·위험관리 **원칙**을 전남광주형 기금에 **벤치마크**하는 것이다. 전남광주 기금의 규모, 목적, 법적 구조, 지역 특수성에 맞게 독자적으로 설계되어야 한다.

## 6. 환헤지 정책

### 6.1 환헤지 기본 방향

해외 자산 비중이 50% 이상인 포트폴리오에서 환위험 관리는 핵심이다.

| 자산군 | 환헤지 방향 | 이유 |
|---|---|---|
| 해외주식 | 부분 헤지 (0~50%) | 환노출이 장기 수익에 긍정적 기여 가능 |
| 해외채권 | 완전 헤지 원칙 | 채권은 안정성이 핵심, 환변동 수용 불가 |
| 해외 대체투자 | 개별 투자별 검토 | 인프라·PE 특성에 따라 다름 |

### 6.2 환헤지 비용 고려

- 원/달러 헤지 비용: 금리차 반영 (변동)
- 헤지 비용이 클 경우 헤지 비율 조정 검토
- 환헤지 정책은 연간 검토하여 투자정책서에 반영

## 7. 지역전략투자 세부 모델

### 7.1 지역전략투자 원칙

1. 전체 기금의 5% (권장) — 정치적 압력에 의한 확대 방지
2. 재무적 수익과 지역경제 파급효과 동시 추구 (Double Bottom Line)
3. 순수 보조금이 아닌 금융투자 형태
4. 투자정책위원회·지역전략사업위원회 이중 심사
5. 수익과 성과 모두 공개

### 7.2 투자 방식 비교

| 방식 | 장점 | 단점 | 전남광주 적용 |
|---|---|---|---|
| 펀드 출자(LP) | 전문 VC가 기업 발굴·관리 | 간접 통제 | 우선 적용 권장 |
| 공동투자 | 수익 직접 참여 | 심사 역량 필요 | 대형 프로젝트 |
| 직접투자 | 높은 통제권 | 이해충돌·전문성 부족 | 원칙적 제한 |
| 대출·보증 | 원금 상환 구조 | 수익 제한 | 일부 활용 가능 |

### 7.3 지역전략투자 심사 기준

지역전략투자는 다음 기준으로 심사한다:

| 기준 | 세부 내용 |
|---|---|
| 재무적 타당성 | 투자 원금 회수 가능성, 수익률 |
| 지역성 | 전남광주 지역 경제에의 실질적 기여 |
| 고용효과 | 직접·간접 고용창출 규모 |
| 기술혁신성 | 미래산업 분야 해당 여부 |
| 민간 매칭 | 민간 공동투자 여부 |
| 확장성 | 사업의 확장·복제 가능성 |
| 이해충돌 | 위원·운용기관 관련자 여부 |

### 7.4 지역전략투자 수익 측정

**재무적 지표**
- 투자수익률(IRR)
- 투자원금 대비 회수 배수(MOIC)
- 벤치마크(국내 VC 평균수익률) 대비 성과

**비재무적 지표 (지역경제 파급효과)**
- 고용창출 수 (직접·간접)

## 8. OCIO 수수료 구조 방향

### 8.1 수수료 유형

| 유형 | 설명 | 적용 방향 |
|---|---|---|
| 관리 수수료 | 운용자산 대비 고정 비율 | 필수 |
| 성과 보수 | 벤치마크 초과수익의 일부 | 도입 여부 검토 |
| 자문 수수료 | RFI·설계 단계 자문 | 별도 계약 |
| 실비 정산 | 거래 비용, 외부 서비스 | 투명 공개 |

### 8.2 수수료 수준 방향 (시장 참조)

12조 원 규모 OCIO 기준 예상 수수료 범위 (RFI를 통해 시장 검증 필요):

| 항목 | 예상 범위 | 비고 |
|---|---|---|
| 관리 수수료 | 연 0.05~0.20% | 규모 클수록 낮아지는 경향 |
| 성과 보수 | 초과수익의 10~20% | 도입 여부 별도 검토 |
| 12조 원 기준 관리 수수료 | 연 60억~240억 원 | 협상 여지 있음 |

> 실제 수수료는 RFI 및 공개경쟁 과정에서 결정되어야 한다.

## 9. 성과평가 벤치마크 설계

### 9.1 벤치마크 구성 방향

전남광주 미래전환기금의 성과를 평가하기 위한 참조 벤치마크:

| 자산군 | 참조 벤치마크 (예시) |
|---|---|
| 해외주식 | MSCI ACWI (전세계 주식 지수) |
| 국내주식 | KOSPI 200 |
| 국내채권 | KTB Index (국고채) |
| 해외채권 | Bloomberg Global Agg (원화헤지) |
| 대체투자 | 사전 협의한 유사 펀드 벤치마크 |
| 종합 포트폴리오 | 가중평균 벤치마크 또는 목표수익률 |

> 벤치마크는 투자정책서에서 확정하며, OCIO 기관과의 협의를 거쳐야 한다.

### 9.2 성과평가 주기

| 평가 주기 | 평가 내용 |
|---|---|
| 월간 | 포트폴리오 평가액, 위험지표 모니터링 |
| 분기 | 자산군별 수익률, VaR, 운용보고서 |
| 연간 | 종합 성과평가, 벤치마크 대비 분석, 의회 보고 |
| 3~5년 | 장기 성과 종합 평가, 투자정책서 재검토 |
